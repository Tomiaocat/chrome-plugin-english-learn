# 体验版验证记录

日期：2026-10-23。版本：0.3.0。

## 自动检查

`npm run check` 通过：

- TypeScript 严格类型检查。
- ESLint，包括业务层和视图层的依赖边界限制。
- 10 个测试文件，43 项测试全部通过。
- WXT / Vite 生产构建成功，未压缩文件合计约 2.37 MB，含约 1.44 MB 的离线词典资源；词典数据不打入内容脚本。

主要覆盖：词频分级阈值及缺失回退、原有20词ID兼容、精选词条质量校验、词库资源SHA-256、惰性/并发加载、查询去重/排序/结果上限、普通词典词条收藏复习和导入时重取标准释义、中文UTF-16分词边界、复合词保护、10,000词前缀树压力用例，以及原有替换预算、AI输出位置、复习事务、幂等、消息来源授权、三协议响应、失败降级、逐网站AI同意、请求限额和跨文档缓存映射。

## 真实浏览器验证

独立 Chrome 155 测试 profile，通过官方 CDP 扩展开发接口加载测试副本。未安装到用户的日常浏览器。v0.3 生产扩展按用户要求声明 HTTP/HTTPS 全网站权限，测试副本使用同样的权限声明，不再额外注入 localhost 权限。

命令：PowerShell 设置 `TEST_CHROME_CHANNEL=chrome` 后运行 `npm run test:e2e`。1 条包含完整交互的浏览器测试通过，含默认开启、停用/刷新/恢复、离线词典和复合词流程的一轮耗时约 40 秒。

新增单元验证：旧设置缺少 excludedSites 时迁移为空停用名单，原偏好与 AI 同意保留；后台繁忙返回重试时，页面不会丢失尚未处理的文本。全局暂停和停用名单先于 AI 判断，默认扫描仍不自动授予任何网站 AI 文段同意。

验证内容：

- 扩展设置页加载和后台消息响应。
- 新网站无需逐站开启即可替换，弹窗显示“当前网站：默认开启”；点击停用恢复中文，刷新后仍不注入，重新开启后无需刷新即可恢复替换。
- 真实中文网页自动替换与词卡可点击、可收藏。
- 输入框和代码不被修改。
- “项目经理查看时间戳和环境变量”保持完整中文，不在复合词内部替换。
- 重复收藏仅产生一个词条，刷新后仍保留。
- 主动复习和下一次复习调度。
- 浏览器断网模式下查询随包词典、收藏 abandon、复习并显示无配套例句的真实状态。
- 普通词典词条参与导出和导入，当前学习进度保持不变。
- 协议选择、保存供应商和 Key 默认仅会话保存。
- 网页内容脚本无法读取完整后台快照或服务配置。
- 数据导出不含测试 Key；导回相同备份不会覆盖当前记录。
- 关闭替换恢复原文；再次开启后处理更新后的网页文本。

v0.1 浏览器测试修复了浮层 reset 覆盖坐标的问题。v0.2 已查看离线词典查询和收藏结果截图，未发现布局溢出。

原始 ECDICT CSV 固定提交并校验 SHA-256；筛选 770,611 个数据记录，生成 16,053 词头精简包。170 个精选义项均找到源词头，其中169个有有效词频；plugin 使用人工档位。缺少音标的3个词保持留空，不生成虚假读音。随发行包携带源MIT许可。

从固定 CSV 再次运行构建脚本，生成的词典 SHA-256 与首次生成一致：`f5ae457e92e63572193c918495507c175acae18a9ae7fa0733ee5038cd9a2899`。

## 尚未验证或未交付

- 真实 DeepSeek、OpenAI、Anthropic 及第三方平台请求：没有使用真实 Key，不产生真实模型费用。协议测试使用模拟响应；实际兼容性由设置中的连接测试进一步验证。
- v0.3 在用户日常浏览器中的升级权限确认尚未操作；由用户重新加载并确认 Chrome 的网站访问权限。隔离测试不等于所有真实工作站点兼容性保证。

- 账号、云同步、学习统计、发音和完整复习事件备份。

Playwright 下载的 Chromium 156 在此 Windows 环境启动返回 `spawn UNKNOWN`；已用可正常启动的官方 Chrome 155 完成上述验证，不将下载版的失败记作测试通过。
